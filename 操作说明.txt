七、每次重启，什么会变、什么不变
--------------------------------------------------------

    本机地址 http://localhost:8080     永远不变
    公网地址                           每次重开隧道都会变
    手机桌面上的图标                   指向旧地址，要删掉重新添加
    二维码                             同上，要重新生成

    所以：发给别人时，永远发最新的那一串。


--------------------------------------------------------
八、常见问题
--------------------------------------------------------

现象：双击 ps1 一闪就没了 / 报语法错误
原因：脚本被编辑器改成了「UTF-8 无 BOM」，PowerShell 5.1 把中文
      当 GBK 读，直接语法崩溃
解决：把脚本重新存成「UTF-8 带 BOM」；或让我来修

现象：提示「因为在此系统上禁止运行脚本」
解决：powershell -ExecutionPolicy Bypass -File .\启动全部.ps1

现象：提示 8080 被占用 / 应用起不来
解决：Get-Process java | Stop-Process -Force
      然后重新启动

现象：手机上打不开，电脑上正常
原因1：手机连着 WiFi（第一次可能被隧道拦）→ 换移动流量
原因2：隧道窗口被关了 → 重新跑隧道
原因3：电脑休眠了 → 唤醒后重开隧道

现象：打开是 404 / ERR_HTTP_RESPONSE_CODE_FAILURE
原因：隧道断了（免费隧道会过期，或电脑断网/休眠）
解决：重开隧道，拿新地址，重新生成二维码

现象：页面能开，但点交卷报错
原因：AI 那边的问题（key / 余额 / 网络 / 超时）
解决：看应用窗口里的红字，提示已经很具体了

现象：输入口令进不去
解决：区分大小写，正确的是 coach2026

十、功能说明（现在有什么）
--------------------------------------------------------

    1. 题库      /question.html
       42 道题（你归纳里 13 道 + 我补的 29 道经典题）
       支持关键词搜索、按分类筛选

    2. 答题      /answer.html?id=题号
       写回答 → 提交 → AI 给分 + 点评 + 漏掉的点 + 追问
       低于 60 分自动进复盘本

    3. 复盘      /review.html
       最烂的排最前面，可以标记「已掌握」

    4. 模拟面试  /mock.html      ★ 新功能
       上传简历（PDF/TXT）→ AI 读懂 → 出 10 道针对你的题
       项目 3 / Java 基础 3 / 数据库 2 / 框架 2
       一题一题问，答完给分、给追问，最后出报告
       评分标准：主干对 75-90，漏关键点 55-75，
                 只会背名词 35-55，答错 0-35

十三、一个必须知道的限制
--------------------------------------------------------

    现在是「免费隧道 + 你家电脑」的方案：
        - 电脑必须开着、不能休眠

    只有一条路：买台学生机（约 10 元/月），
    把 jar 传上去跑，或者用 Docker 部署。

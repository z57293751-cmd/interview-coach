二、服务器上怎么管理这个服务
--------------------------------------------------------

    登录服务器：
        腾讯云控制台 → 轻量应用服务器 → 你的实例 → 右上角「登录」
        （网页终端，不用密码）

    常用命令（在服务器终端里执行）：

        看服务状态          sudo systemctl status coach
        看实时日志          sudo journalctl -u coach -f
        重启服务            sudo systemctl restart coach
        停止服务            sudo systemctl stop coach
        开机自启状态        sudo systemctl is-enabled coach

    服务挂了会自动重启（配置了 Restart=always），
    所以正常情况下不需要手动干预。

五、改完代码，怎么更新到服务器
--------------------------------------------------------

    第 1 步：本地打包

        $env:JAVA_HOME = "C:\Program Files\Java\jdk-17"
        cd D:\deepseekworks\interview-coach
        C:\apache-maven-3.5.4\bin\mvn.cmd -DskipTests package

    第 2 步：把 jar 传上去
        用腾讯云网页终端的上传按钮，传到 ~/ 就行；
        或者用 scp（需要配好密钥）：

        scp target\interview-coach-0.1.0.jar ubuntu@129.204.36.182:~/

    第 3 步：在服务器上替换并重启

        sudo cp ~/interview-coach-0.1.0.jar /opt/coach/app.jar
        sudo chown coach:coach /opt/coach/app.jar
        sudo systemctl restart coach

    第 4 步：验证

        curl -s http://127.0.0.1:8080/api/ping

    看到 {"code":0,"msg":"ok"...} 就成了。

七、改口令
--------------------------------------------------------

    在服务器终端执行：

        sudo sed -i 's/^ACCESS_PASSWORD=.*/ACCESS_PASSWORD=你的新口令/' /etc/coach.env
        sudo systemctl restart coach

    确认改成功：

        sudo grep ACCESS_PASSWORD /etc/coach.env

    改完记得重新生成二维码（见第九节）。


--------------------------------------------------------
八、常见问题
--------------------------------------------------------

现象：手机打开一直转圈 / 打不开
原因1：地址写成了 https → 改成 http
原因2：没带 :8080 → 补上端口
原因3：腾讯云防火墙没放行 8080 → 控制台加规则（TCP 8080 / 0.0.0.0/0）

现象：提示口令不对
解决：服务器上可能还是 coach2026，按第七节改成 ljt666

现象：打开是 502 / 无法访问
解决：服务挂了，去服务器执行
        sudo systemctl status coach
        sudo journalctl -u coach -n 50

现象：页面能开，但点交卷报错
原因：AI 那边（key / 余额 / 超时）
解决：看服务日志，提示里会写明是「模型名不对」「key 无效」还是「评分超时」

现象：改了代码但网站没变
原因：没重新上传 jar 或没重启
解决：按第五节走一遍

现象：登录后过一段时间又要输口令
原因：Cookie 30 天过期，正常现象

十一、数据备份（还没配，先手动）
--------------------------------------------------------

    服务器上手动备份一次：

        sudo mysqldump -uroot coach | gzip > /root/coach-$(date +%Y%m%d).sql.gz

    下载到本地（在 Windows 上执行）：

        scp ubuntu@129.204.36.182:/root/coach-*.sql.gz .

    恢复：

        gunzip -c coach-20261108.sql.gz | sudo mysql coach

    注意：备份在同一块硬盘上不算灾备，
          建议每周下载一份到自己的电脑。
